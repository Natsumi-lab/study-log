# ISMS（情報セキュリティマネジメントシステム）の要点まとめ

ISMS（Information Security Management System: 情報セキュリティマネジメントシステム）は、  
組織が保有する情報資産を適切に管理・保護し、リスクを低減するための包括的な**「仕組み・枠組み」**です。

単にウイルス対策ソフトやファイアウォールを導入するような「技術的対策」だけでなく、  
組織のルール策定、従業員教育、継続的な改善プロセスを含むマネジメント体制全般を指します。

---

## 1. 情報セキュリティの3大要素（CIA）と追加要素

ISMSにおいて保護対象となる情報資産は、以下の3大要素（CIA）を中心に維持・管理されます。

| 要素 | 定義 | 具体例 |
| :--- | :--- | :--- |
| **機密性 (Confidentiality)** | 許可された人だけが情報にアクセスできる状態を保つこと。 | アクセス権限の制御、データの暗号化、多要素認証（MFA） |
| **完全性 (Integrity)** | 情報や処理方法が正確で、改ざんや欠損がない状態を保つこと。 | デジタル署名、ハッシュ値による改ざん検知、変更履歴ログ |
| **可用性 (Availability)** | 許可された利用者が、必要なときにいつでも情報にアクセスできる状態を保つこと。 | 冗長化（マルチAZ/RAID）、定期バックアップ、DDoS対策 |

### その他の追加要素
* **真正性 (Authenticity)**: 利用者やシステムが主張通りの「本人・本物」であることを確実にする。
* **責任追跡性 (Accountability)**: 操作や変更を行った主体をログ等で後から追跡・証明できる。
* **否認防止 (Non-Repudiation)**: 実行した操作や取引を後から「やっていない」と主張できないようにする。
* **信頼性 (Reliability)**: システムが意図された通りの動作を一貫して実行できる。

## 2. ISMS の標準規格（ISO/IEC 27001）

ISMSに関する国際標準規格として最も広く採用されているのが **ISO/IEC 27001**（日本国内規格では **JIS Q 27001**）です。

* **ISO/IEC 27001**: ISMSの要求事項（体制構築、リスクアセスメント、運用、内部監査など）を定めた規格。第三者認証機関による審査に合格すると「ISMS認証」を取得できる。
* **ISO/IEC 27002**: 27001の附属書Aに記載された「管理策（具体的なセキュリティ対策）」の実践のためのベストプラクティスガイドライン。
* **ISO/IEC 27017**: クラウドサービスの提供・利用に特化したセキュリティ管理策の規格（クラウド版ISMS認証）。

## 3. PDCAサイクルによる継続的改善

ISMSは一度ルールを作って完了するものではなく、**PDCAサイクル**を通じて継続的に維持・改善していくことが求められます。

```
[ Plan (計画) ] ────> 方針策定 / リスクアセスメント / 管理策の決定
       │
       ▼
[ Do (実施) ] ──────> 規程の運用 / 従業員教育 / セキュリティ対策の実装
       │
       ▼
[ Check (評価) ] ───> 内部監査 / モニタリング / 有効性の測定
       │
       ▼
[ Act (改善) ] ─────> 経営陣によるレビュー (マネジメントレビュー) / 是正措置
```

1. **Plan (計画)**:
   * 情報セキュリティ基本方針の策定。
   * 保有する情報資産の洗い出しと**リスクアセスメント**（リスクの特定・分析・評価）。
   * 適用する管理策（リスク対応計画）の選定。
2. **Do (導入・運用)**:
   * セキュリティポリシーや手順書の実装・運用開始。
   * 全従業員に対する情報セキュリティ教育・訓練の実施。
3. **Check (監視・レビュー)**:
   * ルールが守られているかを確認する**内部監査**の実施。
   * インシデントの発生状況やログの監視・分析。
4. **Act (改善・是正)**:
   * 監査結果や変化した環境を踏まえた**マネジメントレビュー**（経営層への報告と見直し指示）。
   * 発見された不適合に対する是正措置の実行。

## 4. ISMS認証取得のメリット

* **対外的な信頼性の向上**:
  * 第三者機関の審査を通過している証明となり、取引先や顧客に対するセキュリティ水準のアピールや入札要件のクリアに繋がる。
* **セキュリティインシデントの発生リスク低減**:
  * 全社的なリスクの可視化と対策により、情報漏洩や不正アクセスのリスクを抑制。
* **社内のセキュリティ意識と統制の強化**:
  * 役割や責任が明確化され、従業員の教育体制が標準化される。
