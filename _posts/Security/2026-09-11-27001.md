# ISO/IEC 27001（JIS Q 27001）と ISO/IEC 27002 の違いと関係性

---

## 1. 概要と一目でわかる比較

情報セキュリティのマネジメントに関する国際標準規格（ISO/IEC 27000シリーズ）において、中核をなす2大規格が **ISO/IEC 27001** と **ISO/IEC 27002** です。

* **ISO/IEC 27001（日本規格：JIS Q 27001）**:  
  組織が情報セキュリティを管理するための「仕組み（マネジメントシステム）」の**要求事項（必須ルール）**を定めた規格。**第三者認証（ISMS認証）の対象**となる。
* **ISO/IEC 27002（日本規格：JIS Q 27002）**:  
  ISO/IEC 27001 の附属書Aに並んでいる各セキュリティ管理策を、現場で具体的にどう実装・運用すべきかを解説した**実践のためのベストプラクティス集（実践規範・ガイドライン）**。**認証の対象外**。

```
┌────────────────────────────────────────────────────────┐
│ ISO/IEC 27001 (JIS Q 27001) 【要求事項 / Requirements】 │
│ ・認証基準 (合否を判定するモノサシ)                     │
│ ・ISMSのPDCAサイクル (体制、方針、リスク評価など)       │
│ ・附属書A：管理策のタイトル・目的の一覧 (ダイジェスト版)│
└──────────────────────────┬─────────────────────────────┘
                           │ 具体的かつ詳細な手引き
                           ▼
┌────────────────────────────────────────────────────────┐
│ ISO/IEC 27002 (JIS Q 27002) 【実践規範 / Code of practice】│
│ ・認証基準ではない (ガイドライン・手引書)               │
│ ・附属書Aの各管理策に対する詳細な実装ガイダンス・解説   │
│ ・属性（#予防、#検知、#機密性、#IT など）による分類     │
└────────────────────────────────────────────────────────┘
```

### 比較一覧表

| 比較項目 | ISO/IEC 27001（JIS Q 27001） | ISO/IEC 27002（JIS Q 27002） |
| :--- | :--- | :--- |
| **位置づけ** | **ISMSの要求事項（Requirements）** | **管理策の実践規範（Code of Practice）** |
| **認証の可否** | **認証可能**（「ISMS適合性評価制度」の基準） | **認証不可**（あくまで手引き・ガイド） |
| **文末の表現** | 「〜しなければならない」（shall / 義務） | 「〜することが望ましい」（should / 推奨） |
| **主な対象読者** | 経営陣、監査人、審査機関、推進責任者 | システム管理者、現場実務担当者、セキュリティ設計者 |
| **内容の構成** | 本文（箇条4〜10のマネジメント要求事項）＋ 附属書A（管理策一覧） | 本文（4分類の管理策の詳細な実装手引き） |

## 2. ISO/IEC 27001（JIS Q 27001）の詳細

### (1) 本文（箇条4〜10）とマネジメントシステム
ISO/IEC 27001 の本体は、ISMS（Information Security Management System）という「PDCAサイクルを回すための組織的な仕組み」を規定しています。

* **箇条4：組織の状況**（組織の内外の課題特定、利害関係者のニーズ）
* **箇条5：リーダーシップ**（経営層のコミットメント、方針の確立、役割分担）
* **箇条6：計画**（情報セキュリティリスクアセスメント、リスク対応計画）
* **箇条7：支援**（資源、力量、意識向上、コミュニケーション、文書化した情報）
* **箇条8：運用**（計画したリスク対応の実行・管理）
* **箇条9：パフォーマンス評価**（監視、測定、内部監査、マネジメントレビュー）
* **箇条10：改善**（不適合および是正処置、継続的改善）

### (2) 附属書A（管理策一覧）
* 箇条6のリスク対応において選択するセキュリティ対策のメニュー一覧。
* 2022年改訂版では、**4つのテーマ（組織的、人的、物理的、技術的）**に集約され、計93項目が定義されています。

## 3. ISO/IEC 27002（JIS Q 27002）の詳細

### (1) なぜ 27002 が必要なのか？
ISO/IEC 27001 の附属書Aには、各管理策の概要や目的（例：「バックアップを定期的に取得すること」）しか書かれておらず、具体的にどのような手順や頻度で取得すべきかまでは書かれていません。  
その**具体的な手順、技術的留意点、運用上のベストプラクティスを網羅的に解説した辞書・手引き**が ISO/IEC 27002 です。

### (2) 2022年版での4分類（テーマ）
ISO/IEC 27002:2022 では、管理策が以下の4つのグループに整理されています。

1. **第5章：組織的管理策（Organizational controls） - 37項目**
   * セキュリティ方針、資産目録、サプライチェーン管理、クラウド利用、インシデント管理、BCPなど。
2. **第6章：人的管理策（People controls） - 8項目**
   * 採用前スクリーニング、雇用条件、教育訓練、懲戒手続、退職時の権限削除など。
3. **第7章：物理的管理策（Physical controls） - 14項目**
   * セキュリティ境界、物理的入退室管理、クリアデスク・クリアスクリーン、機器・媒体の廃棄など。
4. **第8章：技術的管理策（Technological controls） - 34項目**
   * 認証管理、最小権限（特権管理）、暗号化、ログ監視、脆弱性管理、セキュア開発など。

## 4. 情報セキュリティ監査人補 試験における頻出ポイント

1. **認証の対象に関する引っかけ**
   * *誤答例*：「当社は ISO/IEC 27002 の適合性認証を取得した」  
     $
ightarrow$ **×（誤り）**。ISO/IEC 27002 はガイドラインであり、第三者認証の対象となる規格は **ISO/IEC 27001** のみ。
2. **経済産業省「情報セキュリティ管理基準」との関係**
   * 経済産業省の「情報セキュリティ管理基準」は、この **ISO/IEC 27001 附属書A および ISO/IEC 27002 をベース**に、日本国内の監査実務に合わせて構成・調整された判断基準です。
3. **文言の性質の違い**
   * 27001 は規格適合のために必須となる**「要求事項（〜しなければならない）」**。
   * 27002 は実装を支援するための**「手引・推奨事項（〜することが望ましい）」**。
