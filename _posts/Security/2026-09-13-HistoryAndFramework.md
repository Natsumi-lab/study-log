制度背景編 第1部

---

## 1. 経済産業省「情報セキュリティ監査制度」の発足背景

日本の情報セキュリティ監査制度は、2000年代初頭のIT社会の急速な進展と、それに伴う新たなリスクへの対応として誕生しました。

```
【制度創設に至る時代背景（2000年代初頭）】
┌─────────────────────────────────────────────────────────────┐
│ ・「e-Japan戦略」(2001年) による高度情報通信ネットワーク社会の推進 │
│ ・電子政府・電子自治体構想、企業のEC・オンライン取引の急拡大│
│ ・相次ぐサイバー攻撃、大規模な個人情報流出事件の多発        │
│ ・「セキュリティ対策を行っている」という企業の主張を客観的に│
│   検証・確認する社会的メカニズム（信頼の鎖）が不在          │
└─────────────────────────────────────────────────────────────┘
```

### (1) 背景の詳細
1. **IT社会基盤への依存とリスクの増大:**
   * 官民を問わず、基幹システムや重要インフラがインターネットに接続され、システム障害や不正アクセスによる被害が社会全体に波及する懸念が高まった。
2. **自己宣言の限界（説明責任の必要性）:**
   * 各組織が「自社はセキュリティ対策をしている」と主張（言明）しても、外部の取引先や利用者はその実効性を確認する客観的な手段がなかった。
3. **市場メカニズムを通じたセキュリティ水準向上:**
   * 法規制による一律の強制（事前規制）ではなく、独立した第三者による監査と適切な情報開示（市場メカニズム）によって、企業が自発的にセキュリティ投資を行う環境を整備することが求められた。

## 2. 制度の目的と基本思想

2003年（平成15年）4月、経済産業省によって**「情報セキュリティ監査基準」**および**「情報セキュリティ管理基準」**が策定・公表され、日本の情報セキュリティ監査制度が本格的にスタートしました。

### (1) 監査制度の3大目的
* **① 情報セキュリティ水準の客観的評価と向上:**
  * 統一された統一基準に基づき、客観的な証拠によって組織のセキュリティ状況を検証し、弱点や課題の是正を促す。
* **② 利害関係者への安心感の付与（説明責任の履行）:**
  * 取引先、顧客、株主、規制当局等のステークホルダーに対し、情報セキュリティが適切に確保されていることを客観的に示し、信頼関係を構築する。
* **③ IT社会全体の安全性・信頼性の確保:**
  * サプライチェーンや電子商取引全体のセキュリティ基盤を底上げし、国民生活と経済活動の円滑な運営に寄与する。

### (2) 制度の基本思想（試験最頻出）
* **行為基準（監査基準）と判断基準（管理基準）の明確な分離:**
  * 監査人の行動規範・手続きを定めた「監査基準」と、組織が講じるべき管理策を定めた「管理基準」を分離することで、監査の客観性と標準化を図る。
* **自主的・自律的な制度:**
  * 法令による一律の義務化ではなく、組織が自らの事業リスクや社会的責任に応じて自発的に受審することを前提とした柔軟な設計。
* **保証型監査と助言型監査の併存:**
  * 外部への証明を主目的とする「保証型」だけでなく、内部改善を主目的とする「助言型」を認めることで、発展途上の組織の底上げにも配慮している。

## 3. 日本セキュリティ監査協会（JASA）の設立と役割

制度の実効性と監査人の質を担保する民間推進機関として、2003年10月に**「特定非営利活動法人 日本セキュリティ監査協会（JASA）」**が設立されました。

```
┌─────────────────────────────────────────────────────────────┐
│ 経済産業省 (METI)                                           │
│ ・「情報セキュリティ監査基準」「情報セキュリティ管理基準」の策定│
└──────────────────────────┬──────────────────────────────────┘
                           │ 官民連携・運用委任
                           ▼
┌─────────────────────────────────────────────────────────────┐
│ 特定非営利活動法人 日本セキュリティ監査協会 (JASA)          │
│ ・監査人資格の認定・登録制度（公認情報セキュリティ監査人）   │
│ ・監査企業（登録監査企業）の認定・情報公開                  │
│ ・各種技術指針・ガイドラインの策定・公表                    │
│ ・監査品質審査・紛争審査・倫理維持                          │
└─────────────────────────────────────────────────────────────┘
```

## 4. 試験対策用：重要キーワード・引っかけパターン

1. **制度の法的強制力に関する引っかけ**
   * *誤答例*：「経済産業省の情報セキュリティ監査制度は、日本国内のすべての株式会社に受審が義務付けられた法定監査制度である」 → **×（財務諸表監査等と異なり、基本的には組織の自主的・自律的な取り組みに基づく任意監査）**
2. **監査基準と管理基準の策定主体**
   * *誤答例*：「情報セキュリティ監査基準はJASAが策定した民間の任意規格である」 → **×（監査基準・管理基準の根本となる基本枠組みは経済産業省が策定した公的基準）**
3. **監査人の役割**
   * *誤答例*：「情報セキュリティ監査制度は、万が一事故が発生した際に監査人がすべての法的賠償責任を肩代わりする保証制度である」 → **×（監査人は合理的な保証を提供するのみであり、セキュリティ対策および事故の最終責任は組織の経営者が負う）**
