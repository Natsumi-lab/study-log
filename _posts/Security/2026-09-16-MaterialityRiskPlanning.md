計画フェーズ編 第2部

---

## 1. 重要性（マテリアリティ: Materiality）の基本概念

情報セキュリティ監査における「重要性（マテリアリティ）」とは、**「その不備・欠陥が存在した場合に、監査報告書の利用者の判断や意思決定に影響を与えるかどうかの境界線・閾値」**を指します。

```
┌─────────────────────────────────────────────────────────────┐
│ 軽微な不備 (重要性基準値 未満)                              │
│ → 改善提言や監査所見には含めるが、適正意見に致命的影響なし │
├─────────────────────────────────────────────────────────────┤
│ ────────── 【 重要性の基準値 (マテリアリティ・ライン) 】 ────────── │
├─────────────────────────────────────────────────────────────┤
│ 重大な不備 (重要性基準値 以上)                              │
│ → 無限定適正意見を出せない (限定付適正意見や不適正意見の要因)│
└─────────────────────────────────────────────────────────────┘
```

* **なぜ重要性の設定が必要なのか:**
  * 監査資源（時間・要員）は有限であるため、組織のあらゆる事象を100%悉皆（全件）チェックすることは不可能。
  * 些細な形式的ミスに拘泥せず、**「利用者の意思決定にとって本当にクリティカルなリスク・不備」に監査資源を集中させるため**に設定する。

## 2. 重要性（マテリアリティ）の設定基準（2つの評価軸）

重要性の基準値は、**「金額的・数量的（量的）側面」**と**「性質的・質的（質的）側面」**の両面から総合的に勘案して決定されます。

### (1) 量的マテリアリティ（金額・件数・数値基準）

数値データとして測定可能な客観的指標に基づく基準。

| 指標カテゴリ | 具体的な設定指標の例 | 監査上の着眼点 |
| :--- | :--- | :--- |
| **金銭的影響度** | 想定損害額、売上高に対する割合（例：売上の○%以上）、対策費用 | 損害賠償額やシステム停止に伴う機会損失の規模。 |
| **件数・影響範囲** | 保有個人情報件数（例：○万件以上）、影響を受ける顧客・アカウント数 | 漏えい時の社会的影響やブランド毀損のインパクト。 |
| **時間・稼働率** | 目標復旧時間（RTO）の超過許容値、システムダウン許容時間 | 業務継続に致命的な支障をきたす停止時間の閾値。 |

### (2) 質的マテリアリティ（性質・文脈による重要度）

数値や金額の多寡にかかわらず、**その事象自体の性質や社会的影響から「重大」と判断される要素**。

| 評価の視点 | 具体例 | なぜ重大とみなされるか |
| :--- | :--- | :--- |
| **法令・規制違反** | 個人情報保護法、マイナンバー法、GDPR等の重大な法令違反 | 行政処分、課徴金、刑事罰などの直接的リスクが生じるため。 |
| **特権の不正・悪用** | 特権管理者ID（root/Administrator）の不正使用・放置 | システム全体の掌握・全データ破壊・改ざんが可能となるため。 |
| **意図的な不正・隠蔽** | 経営者・管理者による不正行為、意図的なログ消去・事実隠蔽 | 内部統制の前提が根底から崩壊しているため。 |
| **社会的信用・評判** | 企業の存続を揺るがすブランド毀損、メディア報道リスク | 株価急落や取引停止など不可逆的な損害を招くため。 |

## 3. 監査計画および実施への反映（計画マテリアリティと実務）

重要性の基準値は、監査計画の段階で仮定され、監査の深さやサンプリング件数を決定する基礎となります。

```
【マテリアリティと監査手続きの関係】
重要性の基準値を「低く」設定 (より厳格・小さな不備も許容しない)
  └──► 必要な監査証拠の量が増大 ──► サンプリング件数を増やす、実証手続を強化
重要性の基準値を「高く」設定 (ある程度の大まかなリスクを許容)
  └──► 必要な監査証拠の量は減少 ──► 効率的なサンプリング、簡素な分析的手続
```

### 段階的なマテリアリティの考え方
1. **業務全体のマテリアリティ（財務・全体レベル）:**
   * 監査報告書全体として意見表明を左右する最上位の閾値。
2. **手続実施上の重要性（Performance Materiality）:**
   * 個々の監査手続を実施する際に設定する基準値。未発見の不備の蓄積を考慮し、**全体基準値よりもやや低めの値（例：全体基準の50%〜75%程度）**に設定して、見逃しを防止する。

## 4. 試験対策用：重要キーワード・引っかけパターン

1. **金額・数値のみによる一律判断の誤り**
   * *誤答例*：「損害想定額が事前に設定した金額基準値（量的マテリアリティ）未満である不備は、その内容がいかなる重大な法令違反や不正であっても、すべて軽微な事項として扱ってよい」 → **×（質的マテリアリティを考慮しなければならない。法令違反や特権不正は金額に関わらず重大事項となる）**
2. **重要性の基準値の固定化**
   * *誤答例*：「重要性の基準値は監査計画書で定めた数値であり、往査中に新たな事実や予期せぬリスクが発覚した場合であっても、一度決めた基準値を変更してはならない」 → **×（監査の進行状況や新たな情報の発見に応じて、監査人は重要性の基準値を適時見直すことができる）**
3. **重要性と監査証拠の量の関係**
   * *誤答例*：「重要性の基準値を低く設定する（厳格にする）ほど、監査人はより少ない監査証拠で意見表明を行うことができる」 → **×（基準値を低く設定するほど、些細な不備も見逃せないため、より多くの監査証拠・詳細な手続が必要となる）**
